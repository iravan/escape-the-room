# Escape the Room

A 3D escape room in the browser that teaches Japanese: you're locked in a gallery after closing time, and solving its
puzzles teaches you hiragana. Two round, skylit rooms joined by a corridor. Live at https://iravan.github.io/escape-the-room/.

**How to play:** every painting has a plaque under it with a clue: a Japanese word, its romaji and one kana
(e.g. ほし (hoshi) means star. ほ = ho). Paintings are not clickable — walk up and read. You start by the blue door
in the east room; at the far end of the west room a printed hiragana chart lies on a table with fifteen kana missing.
Put the right kana in each hole (columns are consonants, rows are vowels) and the door opens: the game ends.

**Paintings and clues:** images in [`web/public/artworks/`](web/public/artworks/), described in `artworks.json`
(title, artist, year, description, `clue`, and which of the 18 hanging spots it takes). Field reference:
[`web/public/artworks/README.md`](web/public/artworks/README.md). The chart and its missing kana: `web/lib/puzzle.ts`.

## Features

- **Hiragana chart puzzle** — the gojūon chart on a table at the end of the gallery (`web/components/room/ChartTable.tsx`);
  click it, pick a kana piece from the tray and tap the hole it belongs in. Once every hole is filled, wrong pieces turn red;
  a complete, correct chart ends the game with a recap of the kana learned
- **Paintings** — framed and spotlit in the gallery's hanging spots from a folder + JSON config; each has a clue plaque under it (not clickable)
- **Gallery** — "Richard's Art Gallery – Audio Tour" with its baked lighting, as a React component
  (`web/components/room/GalleryModel.tsx`, generated by gltfjsx) over an optimised model (`web/public/gallery/gallery.glb`);
  hanging spots and walkable floor plan in `web/lib/gallery.ts`
- **Walk around** — drag to look, WASD / touch stick to move; walls and tables block you
- **Showcase** — photo mode, HUD-free showcase mode

Forked from My Gallery (itself forked from My Room, a vinyl bedroom).

## Quick start

```sh
cd web
npm install
npm run dev     # http://localhost:3000
```

Requires **Node ≥ 20.9**. Useful scripts:

```sh
npm run build
npm test        # Vitest: artworks config, floor plan, hiragana puzzle
npm run check   # headless Chrome: screenshots, drag artifact scan, FPS
```

More notes (including the `npm` / pnpm alias on some Macs) live in [`web/README.md`](web/README.md).

## Gallery model

"[Richard's Art Gallery – Audio Tour](https://sketchfab.com/3d-models/richards-art-gallery-audio-tour-0e3e19faa6474fd5974e6a7ed1b221d8)"
by [shinymagic](https://sketchfab.com/shinymagic), licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Changes: hidden helper meshes and the ground disc removed, textures converted to WebP (2048 px for walls and floor,
1024 px for the rest), animation resampled (58 MB → 14.5 MB), drawn unlit. The original pictures stay; each one is hidden
while one of your artworks hangs in its spot.

To redo it from the source file: with gltf-transform remove `XXX_DO_NOT_RENDER` and `Circle001`, prune/dedup/weld/resample,
WebP textures (no meshopt: its quantisation makes gltfjsx place meshes at the wrong scale), then
`npx gltfjsx@6.5.3 gallery.glb -t -p 6` (6 decimals: the root scale is 0.0012077, and the default 3 rounds it to 0.001) and re-apply the edits noted at the top of `GalleryModel.tsx`.
